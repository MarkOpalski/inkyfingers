I have been wondering how people actually use AI day to day, so I started asking. That curiosity turned into a small, informal exercise: capture a picture of how people use AI today, starting with myself.

I built a benchmark to measure my own usage — not by number of sessions, but by how AI fits into my thinking, building, and workflows.

## The prompt

Paste this into ChatGPT, Claude, or any LLM and see where you land:

```
Help me benchmark my AI usage against U.S. and global norms.

Break down my behavior across:
– Initial prompts per session
– Refinement or follow-up count
– Average session time
– Whether I revisit topics across days
– Complexity of my prompt chains

Then compare me to:
– U.S. users by generation
– Power users and developers
– Creative and strategic users

Classify my usage type (casual, builder, strategist, etc.)
and estimate my percentile (e.g., top 10%, 1%, etc.).
```

### Optional add-ons for better accuracy

You can improve the output by including:

- How many sessions/week you typically have
- What tools you use (e.g., ChatGPT, Copilot, Perplexity, Claude, etc.)
- A few examples of real AI tasks you've done
- Whether you return to topics over multiple days

## What running it on myself turned up

I ran the prompt on myself and got back a full breakdown across every category above: prompt volume, session length, topic persistence, and a percentile estimate against the comparison groups. The point isn't the specific number I landed on — it's that the categories themselves are useful. Most people have never had their own AI usage described back to them in behavioral terms rather than raw session counts, and the gap between how you think you use these tools and how the pattern actually reads is usually where the interesting finding is.

## Why this matters

Understanding how you use AI, compared against real behavioral categories, can surface blind spots and show where you sit relative to others. It's a self-audit for the AI era.

If you run this prompt, I'd like to know what kind of user you turned out to be — I'm collecting patterns for a follow-up piece on human-AI use cases.
